# Manual checklist (real devices)

Do this on **both** the phone and the tablet. Tick each box as you go. If something fails, note which device and what happened.

| | Phone | Tablet |
|---|---|---|
| Device model / Android version | | |
| Date checked | | |

## 1. Install
- [ ] Phone  - [ ] Tablet: Open https://jonbooth94.github.io/color-critters/ in Chrome, wait for the animals to appear, then **⋮ → Install app** (or **Add to Home screen**).
- [ ] Phone  - [ ] Tablet: The **Color Critters** icon (yellow background, orange cat) is on the home screen and looks right, not cropped.
- [ ] Phone  - [ ] Tablet: Opening it from the icon goes **full screen in landscape**: no address bar, no status bar.
- [ ] Phone  - [ ] Tablet: All 10 animals show on the picker as large pictures with no text.

## 2. Airplane mode: every animal
- [ ] Phone  - [ ] Tablet: Open the app once online, then close it fully (swipe it away in Recents).
- [ ] Phone  - [ ] Tablet: Turn on **airplane mode** (and make sure Wi-Fi is off).
- [ ] Phone  - [ ] Tablet: Open the app from the home screen. It loads.
- [ ] Phone  - [ ] Tablet: Open **each** animal, color a little, then tap Home:
  dog ☐ cat ☐ octopus ☐ prairie dog ☐ elephant ☐ lion ☐ fish ☐ duck ☐ turtle ☐ cow ☐
- [ ] Phone  - [ ] Tablet: Turn airplane mode off when done.

## 3. Drawing feel
- [ ] Phone  - [ ] Tablet: **Fast scribbling** back and forth gives smooth, solid lines, no gaps, no jagged corners, no lag.
- [ ] Phone  - [ ] Tablet: A **single tap** leaves a dot.
- [ ] Phone  - [ ] Tablet: Color goes **under** the black outlines; the outlines always stay visible.
- [ ] Phone  - [ ] Tablet: Each crayon draws its own color. The selected crayon is clearly highlighted. Each tap makes a soft pop.
- [ ] Phone  - [ ] Tablet: **White** paints over colors (works as an eraser).

## 4. Kid-proofing: multi-finger mashing
- [ ] Phone  - [ ] Tablet: Draw with one finger, then put a second finger down and move both. Only the first finger draws, and no line jumps between fingers.
- [ ] Phone  - [ ] Tablet: Mash the screen with several fingers and a palm for ~10 seconds. Nothing crashes, nothing freezes.
- [ ] Phone  - [ ] Tablet: Pinch and double-tap: the page **doesn't zoom**.
- [ ] Phone  - [ ] Tablet: Long-press anywhere: **no menu, no text selection, no "save image"**.
- [ ] Phone  - [ ] Tablet: Pull down from the top of the picker: **no pull-to-refresh**.

## 5. Leaving and returning
- [ ] Phone  - [ ] Tablet: Color an animal, then press the device **Home** button right away (within a second). Reopen the app: the coloring is still there.
- [ ] Phone  - [ ] Tablet: Color, then swipe the app away in Recents. Reopen: the coloring is still there.
- [ ] Phone  - [ ] Tablet: Tap the in-app **Home** (house) button. The picker thumbnail for that animal shows her coloring.
- [ ] Phone  - [ ] Tablet: Lock the screen while coloring, unlock: still on the same drawing, nothing lost.

## 6. Clear (press and hold)
- [ ] Phone  - [ ] Tablet: A **quick tap** on the clear (eraser) button does nothing.
- [ ] Phone  - [ ] Tablet: Holding it shows a **pink ring filling** around the button. Letting go early cancels and the drawing stays.
- [ ] Phone  - [ ] Tablet: Holding for **2 seconds** clears the drawing, with a soft whoosh. Go home and back: it's still clear.

## 7. Sound and mute
- [ ] Phone  - [ ] Tablet: Opening an animal plays a gentle chime.
- [ ] Phone  - [ ] Tablet: Tap the small **speaker** button on the picker (top-right). It shows muted; no pops, chimes or whooshes.
- [ ] Phone  - [ ] Tablet: Close and reopen the app: **still muted**. Unmute again.

## 8. Screen pinning
- [ ] Phone  - [ ] Tablet: Pin the app (see README). Swiping home or back doesn't leave the app.
- [ ] Phone  - [ ] Tablet: Unpinning asks for your PIN (if enabled).

## 9. Updates keep drawings
1. Color something on the dog and the cat on each device.
2. Make a small, visible change and push it. For example, ask Claude Code to *"add a pig"*, or change an animal's art. Wait for the green check in GitHub **Actions**.
3. On each device, with the device online:
- [ ] Phone  - [ ] Tablet: Open the app and go into an animal and color for a minute. **The app does not reload while you're coloring.**
- [ ] Phone  - [ ] Tablet: Tap Home. Within a few seconds the picker refreshes once (quick flash) and shows the change. If not, close and reopen the app.
- [ ] Phone  - [ ] Tablet: The dog and cat drawings are **still there**.
- [ ] Phone  - [ ] Tablet: Airplane mode again: the new version works offline, including any new animal.
